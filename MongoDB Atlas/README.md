# MongoDB Atlas × MCP 機能検証プロジェクト

## 目的

ChatGPTからMCP経由でMongoDB Atlasと通信し、利用可能な操作、実際の検証結果、必要な権限、制約、注意点を継続的に調査・記録する。

## 検証対象

1. 接続・探索：Atlasプロジェクト、クラスターの一覧・詳細
2. データ参照：データベース、コレクション、ドキュメントの読み取り
3. 検索・分析：条件検索、集計、パフォーマンス情報
4. データ操作：テストデータの追加・更新・削除
5. 管理：インデックス、クラスター、アラートなどの確認
6. セキュリティ：権限、認証、ネットワークアクセス設定の確認
7. 自動化：MCPを利用した定型的な確認作業

利用可能なMCPツールと実際に成功した操作は区別する。

## 管理ファイル

- `README.md`: 目的、範囲、方針、現在の状況
- `WORKLOG.md`: 日付ごとの作業履歴
- `CAPABILITIES.md`: MCP機能一覧と検証結果

## 記録ルール

- 各操作について、操作名、目的、必要な権限、実行日時、結果、制約、次の課題を記録する。
- 状態は「未検証」「成功」「失敗」「対象外」を明記する。
- まず読み取り専用で確認し、書き込みや削除は明示的な承認のもとテスト用データに限定する。
- APIキー、パスワード、秘密の接続文字列、機密ドキュメントの内容は記録しない。
- 実装変更は原則1タスク1PRで行う。記録更新時も変更内容を明示する。
