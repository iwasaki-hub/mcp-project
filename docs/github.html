NOTES

制約と未検証項目

GitHub MCPのワークフロー実行一覧取得はPRイベントと先頭ページに限定されます。Actionsのcheckout@v4でNode.js 20非推奨警告を確認しました。Artifactsの保持期限後の取得はできません。GitHub Pagesの公開設定変更・新規リポジトリ作成は現在の接続ツールでは直接操作できません。
